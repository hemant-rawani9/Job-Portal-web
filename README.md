# 💼 Job Portal

A modern and user-friendly **Job Portal Web Application** designed to connect job seekers with employers. Users can explore job opportunities, search and filter jobs, view job details, and manage their applications through a simple and responsive interface.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/job-portal.git
```

### 2. Open the Project

```bash
cd job-portal
```

### 3. Install Dependencies

For the frontend:

```bash
cd frontend
npm install
```

For the backend:

```bash
cd ../backend
npm install
```

### 4. Configure Environment Variables

Create a `.env` file inside the backend folder:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### 5. Start the Backend

```bash
npm start
```

### 6. Start the Frontend

Open another terminal:

```bash
cd frontend
npm start
```

The application will then be available on your local development server.
